PDF Remediator opens a private review workspace in your browser. It keeps your original PDF unchanged, creates a separate result, and shows the work that still needs your judgment.

This is the 0.3 development build for the prepared Windows computer, with optional Auto-fix. A result marked **Ready for review** has passed its required automated checks. ## Open the workspace

Double-click **Start PDF Remediator.cmd** in this folder. Your browser opens the local workspace. It is a web page that runs on this computer, so it looks like one; a stand-alone program window is planned for version 2.0. Double-clicking it again reopens the running application.

If the application environment is missing, run **Setup PDF Remediator.cmd** first. Setup prepares the isolated Python application and may download its required packages. It does not download AI models. The PDF engine, validator, Java, and optional OCR tools must already be prepared separately; this folder is not a complete installer for another computer. [README.md](README.md) has the setup details.

Use **Stop application** at the bottom of the workspace when you want to stop the local helper. Closing the browser tab alone leaves it available for your next visit.

## Recover from an installation path error

Setup checks that the required Python packages can actually load their native components, rather than just checking their installed version numbers. If a required package cannot load, Setup stops and does not report that it is ready.

Some deeply nested Windows folders cannot load the PDF engine's native libraries, even when Windows long paths are enabled. If Setup or Start reports that a filename or path is too long, create a **fresh source copy in a shorter local folder** and run Setup there with that copy's selected `local-runtime.toml`. Do not copy or move the old `.venvs` environment. The selected Java, PDF engine and validator paths must also remain usable.

Leave the existing installation, original PDFs, configuration and saved reviews in place. A new installation does not automatically transfer saved reviews. Use the existing review import and recovery workflow to reopen saved work when needed; do not relocate or rewrite its bound original and result files. This recovery does not require changing Windows settings.

## Process a PDF

1. Click **Choose PDFs** and select a reading or book. For a first run, use a document with selectable text.
2. Open **Processing options** if you need to supply a meaningful title, correct the language, declare the content type, or select a supported recovery option. Leave scanned-text processing off for an ordinary digital reading.
3. Click **Process selected PDFs**. The activity panel shows progress and offers cancellation.
4. Open the document when processing finishes. Compare the original and proposed pages, and read any **Needs attention** message.

Selecting a file copies it into the workspace on this computer. It does not upload the PDF to a cloud service. Each processed document has its own result and evidence.

If a result is withheld, follow the displayed repair path. Signed or password-protected files, known slide decks or equation documents, and other unsupported cases require manual or source-document handling. The application does not silently remove signatures or bypass passwords.

## Review the title and descriptions manually

In **Descriptions & title**, inspect each item and its page context. Enter your name in **Your name for approval records** before accepting values or approving checks.

- **Save edit** saves an editable draft. The PDF does not change.
- **Accept this value** records the value you have reviewed and want applied.
- **Apply accepted edits** creates a new result and reruns the required automated checks. It does not overwrite the original or the previous result.

After applying edits, use the newly opened result and its review queue. The new PDF needs review against its own exact contents. Previous review approvals do not automatically verify changed PDF bytes.

Page previews help you inspect appearance. Selectable page text provides context; it does not establish the correct screen-reader sequence. Description meaning, reading order, table relationships, character accuracy, and the other listed checks still need judgment.

## Review repeated repairs in groups

The **Review checks** tab groups similar work so you can navigate it more easily. For example, repeated list or link repairs can appear together. Every occurrence keeps its own page, evidence, status, and approval record.

Choose a group, inspect each occurrence you intend to approve, and select those occurrences. **Select all shown occurrences** is a selection shortcut; it does not replace reviewing them. Check **I reviewed the selected occurrences and their context**, then click **Approve selected checks**. A reviewer name is required.

Leave uncertain occurrences pending or report a problem on the individual item. One good example does not approve every similar item in the book. Changed context or a changed result invalidates approvals that no longer match.

## Optional local AI drafts

AI is off until you explicitly request it. You can complete the workflow by writing descriptions yourself.

To use an already running local model:

1. Select the title or figure items you want help with. Work with up to eight decisions per request. Human-edited or accepted values are protected.
2. Open **Optional local AI assistance**, keep the service set to the local endpoint, and click **Find installed models**.
3. Choose an installed model. On this prepared computer, `qwen2.5:1.5b` can draft from text and captions. `qwen3.5:latest` also supports images.
4. For a vision model, select **Include figure crops** to send the supported figure crops with nearby text. For the tested Qwen3.5 route, also select **Use fast drafting mode**. Without crops, the model receives text and captions and cannot verify the picture's visual details.
5. Explicitly select sending the chosen context to that local model, then click **Draft selected suggestions**.
6. Inspect each returned suggestion. **Use as editable draft** copies it into a pending value. Edit it as needed, then separately choose **Accept this value**. Use **Apply accepted edits** only when your selected values are ready.

If no model is found, the already installed local model service must be started separately. The application does not install or download a model for you and has no cloud-provider option. Requests are limited to a selected loopback service on this computer; redirects and environment proxies are not used.

In this manual workflow, AI suggestions remain drafts until you accept them. The separate Auto-fix option can apply guesses under your document-level authorization. Neither flow lets the model grant human approval or verification. Reused pictures are considered in their separate caption contexts. Cached suggestions are reused only for matching recorded context and settings.
